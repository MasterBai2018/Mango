## 📢 版本概述

Mango V3.6.0 是一个功能增强和稳定性提升的重要版本。本次更新新增了**CarPlay客户端支持**、**日志断言功能**、**Case级别参数化**等核心特性，同时优化了时间戳同步、多声道音频处理等关键功能，并修复了多个已知问题，进一步提升了框架的易用性和稳定性。

---

## ✨ 核心新功能

### 🎯 1. 新增CarPlay客户端支持
- **新增CarPlayClient测试客户端**，支持CarPlay SDK的完整测试能力
- 支持唤醒词检测、VAD状态、音频数据、状态变化等回调处理
- 扩展了NANO测试套件的客户端类型，现支持**10种客户端类型**（TSA/SET/VOI/OMS/TTS/SYS/EXP/HWK/PST/TIA/CPL）

### 🔍 2. 日志断言功能（[EXP]LOG）
- **新增日志断言指令**，支持对日志文件进行断言验证
- 支持关键字搜索、键值对匹配、JSON提取、正则提取和时间差计算
- 完善了断言体系，现支持**回调断言、API断言、文件断言、日志断言**四大类

### 📊 3. Case级别参数化支持
- **支持Case级别的参数化**，可在mgo文件中为每条Case定制独立的参数化CSV文件
- 新增`-PF`参数，支持按行号范围过滤参数化文件
- 增强了数据驱动测试的灵活性，支持更细粒度的参数化控制

### 📝 4. Case级别简介支持（BREF指令）
- **新增SYS客户端的BREF指令**，支持为每个Case设置独立的简介信息
- 支持终端输出CaseIndex，便于测试执行过程中的用例追踪
- 附件指令支持输出CaseIndex，提升报告可读性

### 🛠️ 5. 测试工具增强
- **新增声纹FA测试用例生成脚本**，自动化生成声纹测试用例
- **新增唤醒FA/FR测试分析工具**，支持唤醒准确率和误唤醒率分析
- **新增必过集识别率分析工具**，支持识别率统计分析
- **新增VAD测试工具**，支持VAD功能专项测试
- **新增长音频短音频识别劣化率对比工具**，支持音频长度对识别效果的影响分析
- **新增AI能力平台测试工具**，支持AI能力平台接口测试
- **新增SDK转mgo文件脚本工具**，支持将SDK测试用例转换为mgo格式

### 🐳 6. Docker支持增强
- **新增Docker GDB调试支持**，支持在Docker容器中进行GDB断点调试
- **优化Docker用户组管理**，解决权限问题
- **优化Docker时间同步**，容器时间与宿主机同步
- **修复Docker进程管理问题**，解决容器删除后的孤儿进程问题

## 🚀 功能优化

### ⏱️ 时间戳优化
- **优化TSAP时间戳处理机制**，提升时间戳精度和一致性
- **修复多客户端送音频时时间戳不同步问题**，确保多客户端并发测试时时间戳的一致性
- **优化事件时间戳设置**，统一使用系统时间戳

### 🎤 声纹功能优化
- **优化声纹注册格式统一**，保持REGISTER_VOICEPRINT_LIST声纹注册时的格式统一
- **优化声纹列表获取**，支持排序功能
- **优化声纹登录协议**，调整VOICEPRINT_LOGIN协议与DATA保持一致
- **优化声纹用户列表输出格式**，提升可读性
- **修复车参设置与声纹列表获取的BUG**

### 🎵 音频处理优化
- **修复多声道传音频时切片错误问题**，确保多声道音频正确传输
- **优化音频时间戳处理**，修复AI工具保存时间戳的问题
- **优化音频下载功能**，修复无法下载FTP音频的BUG

### 📈 报告生成优化
- **优化ASR报告保存逻辑**，修复ASR结果为空时报告没写入的BUG
- **优化Allure附件上传**，修改ASR保存结果的allure附件上传逻辑
- **优化报告中置信度解析**，增加报告中解析置信度功能
- **优化语种输出报告**，支持多语种测试结果统计

### 🔧 其他优化
- **优化断言逻辑**，去掉&的断言逻辑，支持多种断言方式
- **优化DSL解析引擎**，当没有参数化参数时跳过Command解析
- **优化TEXT指令**，修复传入英文空格时产生错误断句的问题
- **优化日产项目支持**，支持日产自动化Case，添加日产Jenkins自动下载支持
- **优化PSTT测试Suite**，调整PSTT测试工具结果
- **优化SpeechEngine支持**，SpeechEngine单独支持测试可见可说
- **优化客户端创建逻辑**，如果AIBS的客户端不是TSA，则不用等待create成功的信号

## 📖 使用指南

### 快速开始
```bash
# 基础运行
python3 Run_Mongo.py -f NANO \
  -C TestCase/conf/decoder.conf \
  -a TestCase/caselist/nano.mgo \
  -b 24mm

# 使用新功能：Case级别参数化
python3 Run_Mongo.py -f NANO \
  -C TestCase/conf/decoder.conf \
  -a TestCase/caselist/nano.mgo \
  -b 24mm \
  -P TestCase/data/test_data.csv \
  -PF 10-20

# 使用新功能：日志断言
# 在mgo文件中使用: [EXP]LOG {logfile} keyword:value <timeout=5>
```
